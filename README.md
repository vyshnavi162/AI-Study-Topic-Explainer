# AI Study Topic Explainer

A modern AI-powered web application that helps students quickly understand academic topics. Enter any topic and receive a clear, concise explanation generated by the **Google Gemini API**.

## ✨ Features

- **Topic Input** — Type any academic topic (e.g. *Photosynthesis*, *Newton's Laws*, *Binary Search*).
- **AI Explanation** — Get a short, student-friendly explanation in 4–6 sentences.
- **Responsive Design** — Looks great on desktop and mobile.
- **Loading & Error States** — Smooth spinner and friendly error messages.
- **Fast & Lightweight** — Built on Next.js App Router with server-side API routes.

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **npm** (comes with Node.js)
- A **Google Gemini API key** — get one free at [Google AI Studio](https://aistudio.google.com/app/apikey)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/ai-study-topic-explainer.git
cd ai-study-topic-explainer

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env.local
# Then open .env.local and paste your Gemini API key

# 4. Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```env
GEMINI_API_KEY=your_api_key_here
```

> **Note:** Never commit your API key to version control. `.env.local` is already in `.gitignore`.

## 🤖 How the Gemini API Works

1. The user submits a topic from the frontend.
2. The frontend sends a `POST` request to `/api/explain` with `{ "topic": "..." }`.
3. The API route (`app/api/explain/route.ts`) validates the input and calls `lib/aiClient.ts`.
4. `aiClient.ts` sends a prompt to the **Gemini REST API**:
   ```
   Explain the topic "{topic}" in simple, clear language suitable for a student.
   Keep the explanation short and easy to understand. Use at most 4 to 6 sentences.
   ```
5. The Gemini model returns a generated explanation.
6. The API route sends the explanation back to the frontend as JSON.
7. The `ExplanationCard` component renders the result.

## ☁️ Deployment (Vercel)

1. Push your project to **GitHub**.
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Add the environment variable:
   - **Name:** `GEMINI_API_KEY`
   - **Value:** your API key
4. Click **Deploy**.
5. Your app will be live at a URL like `https://ai-topic-explainer.vercel.app`.
